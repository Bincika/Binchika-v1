# Evidence storage, IPFS and costs

## Design: takedown-resistant without paying for everything twice
1. **Primary blob store: Cloudflare R2.** Every evidence image (client-compressed EC8A photo, about 300 KB, plus a 30 KB thumbnail) is stored under its SHA-256. R2 has no egress fees, which matters most when the public views images.
2. **Content addressing for everything, pinning for some.** For every image and ledger entry Binchika computes an IPFS **CIDv1** (sha2-256, raw codec) and writes it into the ledger. A CID can be computed without pinning, so anyone holding a copy can prove it is the exact file the ledger names, even if binchika.com disappears.
3. **Selective pinning (Pinata free tier: about 500 files / 1 GB).** Only **high-confidence** units are pinned, as **bundles**: one CAR file per state per election day, holding the ledger entries plus the evidence images for high-confidence units. That is 37 × 2 = 74 bundles per cycle, well within 500 files. Any overflow beyond 1 GB goes to a second free pinning service (Storacha) and to partner pinners.
4. **Mirrors.** Ledger JSON is mirrored to GitHub (public repo and releases). Bundle CIDs are published so universities, journalists and civil-society partners can pin them too. The more independent pinners there are, the harder a takedown becomes.
5. **What a takedown cannot erase:** ledger hashes and CIDs already copied to GitHub and partner pins, and every chain-verified snapshot people downloaded (CSV/JSON from `/ledger/`).

## Cost model (one general-election cycle, 2 election days, 12-month retention)

**Recommendation: Cloudflare R2.** It is the cheapest in every scenario (about 3× cheaper than the hyperscalers) because public viewing creates heavy egress and R2 charges none for it.

**Cutting the overrun case further** (not yet modelled in the numbers):
- Drop duplicate photos by perceptual hash, and keep full images for one photo per reporter per sheet.
- Move images to R2 Infrequent Access after 30 days.
- After tribunal windows close, keep thumbnails plus bundles only.

## Grant and in-kind paths (no outcome promised)
- **Cloudflare Project Galileo**: free advanced protection for at-risk public-interest websites, including civic and election-integrity groups. Apply via cloudflare.com/galileo.
- **Filecoin Plus / Filecoin Foundation for the Decentralized Web**: programmes for storing public-good datasets on Filecoin and grants for decentralised-web civic projects.
- **Open-source and democracy funders**: for example open-technology and democracy-support funds that back election-integrity tooling. Check eligibility for a non-partisan, citizen-run project.

Eligibility and terms change. Treat these as leads to research, not commitments.
